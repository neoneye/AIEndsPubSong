# AI Ends Pub

Source code for the music video for *AI Ends Pub*, a dystopian military march built from the best lines and memes posted over six months in the "AI Ends Pub" Discord, a server about AI safety.

The video is a **Skynet UI**, red on black. Every meme arrives as an `INTERCEPTED TRANSMISSION`. A T-800 reticle scans the image and **locks onto the exact detail the lyric is about** (`MATCH FOUND`), the camera zooms in, and the locked box shows in full colour. Lines without a meme are acted out by rigged red wireframe endoskeletons. A P(DOOM) meter climbs through the song: it slams to 75.5% when the Humanity Casino's own P(DOOM) board is locked in chorus 2, and it reaches 99.9% before the screen asks you to **insert disk 2**.

## Rendering

You need Node.js, Google Chrome and ffmpeg (`brew install ffmpeg`).

```bash
npm install
node render.mjs --prep                                  # extract the T2 clip to frames (out/t2)
node render.mjs --frames=0:284.7 --workers=6            # paint every frame into out/frames (resumable)
node render.mjs --encode --out=out/ai_ends_pub.mp4      # join the frames and the song into an MP4
node render.mjs --thumbs                                # three YouTube thumbnails → out/thumbnails
```

Quick checks:

```bash
node render.mjs --sheet=10,15,20 --out=out/sheet.jpg    # contact sheet
node render.mjs --clip=0:12 --out=out/clip.mp4          # short clip with audio
```

Outside macOS, add `--chrome=<path to chrome>`.

## How the timing was found

[`tools/transcribe.py`](tools/transcribe.py) runs whisper.cpp (large-v3-turbo) on overlapping 30 s chunks with no context carry-over, which stops whisper from looping on the chorus. [`tools/align.py`](tools/align.py) matches those words to `assets/lyrics.txt` and interpolates the rest. Lines whisper could not hear (the chorus wail, the "(future, future)" echoes) are pinned by hand. The tempo, a steady 93 BPM, comes from spectral-flux autocorrelation.
